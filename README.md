## 什么是 Crab-Burrows
`Crab-Burrows` 是一个用 Rust 从零实现的轻量级, 个人学习性质的嵌入式数据库。包括SQL解析，查询优化，执行引擎，存储引擎，事务操作等内容。

## 为什么开发 Crab-Burrows
- 个人基于学习的深入实践 Rust 核心特性：所有权, 借用, 异步, 零拷贝等  
- 理解 SQL 内部实现
